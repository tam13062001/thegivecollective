    Status is Meta's delivery status when the data was pulled. Actions: Pause an active ad set with no purchase after the minimum spend; Raise budget on active winners; Reopen a paused ad set that beat the target ROAS (to test, when it has only one purchase); Retry with new creative when a paused ad set had purchases at a lower ROAS. ROAS is purchase value divided by ad spend. A purchase is the Meta pixel's Purchase event on thegivecollective.com. CTR uses link clicks; LPV is a landing-page view. Periods end on the latest day in the data and compare with the same number of days just before.
